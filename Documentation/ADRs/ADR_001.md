*ADR_001: Choix de la technologie pour le projet

**Contexte:
Pour commencer le projet on doit établir les technologies que l'on va utiliser. Le projet va être sur un site donc il faut choisir le language qui va être utilisé. Ils faut que tout les membres puissent utilisaient cette technologie.

**Décision
Pour les languages, on a décider d'utiliser golang, JS, HTML et CSS.
